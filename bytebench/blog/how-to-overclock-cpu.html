How to Overclock a CPU in 2026: A Practical Guide for AM5 and LGA1851

Marcus Thorn September 28, 2026  ·  13 min read
Modern CPUs already boost aggressively within their power and thermal limits. Manual overclocking in 2026 is mostly about removing artificial constraints and optimizing memory, not dialing in a voltage curve from scratch. Here's the practical approach for both AMD AM5 and Intel LGA1851 platforms.

What "Overclocking" Actually Means Today

Traditional overclocking — setting a fixed all-core frequency above stock — is mostly irrelevant for current AMD Ryzen chips. Zen 5's boost algorithm already runs each core at the highest frequency the chip can sustain within its thermals. Overclocking a 9700X with a fixed all-core overclock (say, 5.2GHz on all cores) typically results in lower multi-core performance than stock because you're removing the single-core boost headroom.

What actually works for AMD: Precision Boost Overdrive (PBO), which gives the boost algorithm more power budget headroom, and Curve Optimizer, which tightens the voltage-frequency curve on a per-core basis. For Intel, it's enabling Multi-Core Enhancement (MCE) and Thermal Velocity Boost, plus memory overclocking via XMP/XMP3 profiles.

Tools You'll Need

  • HWiNFO64 — free, shows all relevant temperatures, voltages, and clock speeds in real time
  • Cinebench R24 — free, standard synthetic workload for sustained multi-core and single-core testing
  • Prime95 or OCCT — stress testing tools for stability validation
  • AMD Ryzen Master (AMD only) — lets you configure PBO and Curve Optimizer from Windows without entering BIOS
  • Your motherboard's BIOS — for memory XMP profiles, power limits, and Intel-specific overclocking

AMD Zen 5: Start Here (PBO + Curve Optimizer)

Step 1: Enable PBO in BIOS

Enter your BIOS (usually Delete or F2 at POST), navigate to the CPU overclocking or AMD OC section. Enable "Precision Boost Overdrive" and set it to "Advanced." Set the PPT (Package Power Tracking) limit to +200W above stock, TDC and EDC limits similarly — these numbers sound large but you're removing a software ceiling; the chip won't actually draw 200W more; it'll use whatever its thermals allow.

Step 2: Enable EXPO Memory Profile

In the same BIOS section, find Memory XMP/EXPO and enable the EXPO profile for your RAM kit. If your kit is DDR5-6000 CL30, this will automatically set the correct timings. Save and reboot. Run Cinebench R24 multi-core and note your score. Run HWiNFO to check peak temperatures — if you hit 95°C+ under sustained load, your cooler needs improvement before going further.

Step 3: Curve Optimizer (for more experienced users)

Curve Optimizer adjusts the voltage-frequency curve on a per-core basis. A negative CO offset reduces voltage at each frequency, which allows the chip to either run cooler (and potentially boost higher) or hit the same frequencies more efficiently. Start conservatively with CO set to -10 on all cores. Test stability with Cinebench R24 multi-core x5 runs and a 30-minute Prime95 small FFT test. If stable, move to -15. Most Zen 5 chips are stable at -20 to -30 on most cores; some cores can go to -40.

If you get a crash or blue screen, the CO value is too aggressive. Back it off by +5 and re-test. Per-core tuning (finding the weakest cores and only applying conservative offsets there) is more nuanced — there are excellent guides on AMD's official site and the /r/overclocking wiki for this step.

Intel Arrow Lake: MCE and Memory

Step 1: Enable Multi-Core Enhancement

Intel's MCE removes the processor's power limit constraints and lets the CPU run at its maximum boost frequency on all cores for as long as thermal limits allow. In BIOS: find "Multi-Core Enhancement" or "Performance Turbo Boost Limits" and enable it. This is the single highest-value change for most Intel systems.

Step 2: Enable XMP3 Memory Profile

Intel's memory controller handles high-speed DDR5 better than AMD's in some configurations. Enable XMP or XMP3 in BIOS and select the appropriate profile for your kit. Test for stability with MemTest86 (runs from a USB drive, check for errors over one full pass) and Cinebench R24 multi-core.

Step 3: Thermal Velocity Boost (Z890 boards)

TVB allows the CPU to boost higher than its rated speed when temperatures permit. Enable TVB in BIOS and ensure your cooler can keep the CPU below 70°C under load — that's the threshold where TVB provides its maximum benefit. With a 240mm AIO or better, TVB can add 100-200MHz of effective boost on cooler cores.

These gains are real but not transformational. If you're chasing a 20% performance gain, you'd need to buy a better chip. Overclocking in 2026 is about extracting 5-10% more from what you already have, with some risk and effort. For most people, the time investment is better spent elsewhere unless you enjoy the process itself.

What Can Go Wrong

CPU overclocking can cause system instability (crashes, blue screens), data corruption if a crash happens during a write operation, and reduced CPU lifespan in theory (though this is difficult to quantify in practice). Modern motherboards have safety protections that prevent damage from most amateur-level overclocking attempts. If you see temperatures above 95°C under sustained load, back off immediately and improve cooling before continuing.

Keep a recovery plan: know how to reset your BIOS to defaults (usually a physical CMOS reset jumper or button on the board, or removing the CMOS battery for 30 seconds). If things go wrong, resetting to defaults gets you back to a stable system.

Quick Steps

  • AMD: PBO + EXPO → Curve Optimizer
  • Intel: MCE + XMP3 → TVB
  • Both: Memory speed matters more
